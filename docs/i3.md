# xorg.conf
## 4k monitor
- check current DPI `xdpyinfo | grep dots`
- typically 96x96; doubling typically is fine for 4k
- restart Xserver after
```echo Xft.dpi: 192 >> ~/.Xresources```

## trackpad
### libinput versus synaptics
On current installations (writing onn Debian in 2020) is most likely governed by
libinput, google synaptics if libinput is not installable / already installed.
- check whether xserver-xorg-input-libinput or xserver-xorg-input-synaptics is
  installed
- copy default definition from package to /etc or create your own file
`cp /usr/share/X11/xorg.conf.d/40-libinput.conf /etc/X11/xorg.conf.d/40-libinput.conf`

### tryout values with xinput
settings these in xorg.conf required a restart of the Xserver to activate the
values, so it makes sense to first try them out in the current session with
xinput
- list devices and their IDs
`xinput --list`
- list device options / properties
`xinput --list-props <ID>`
```xinput --list-props 11

        libinput Tapping Drag Enabled Default (331):    1

```
- test desired settings, e.g. reverse scroll direction

# lock
i3lock does not scale or resize the images and only supports PNG.
Imagemagick can convert images and resize them.
To resise ignoring image ratio (!):
`apt-get install imagemagick; convert --scale <px>:<px>\! <oldimg>.<jpg> <newimg>.png`
For a vast list of options check the manpage or the examples on
https://legacy.imagemagick.org/Usage/ e.g. [resize/#noaspect](https://legacy.imagemagick.org/Usage/resize/#noaspect)
Configure screenlock in i3 config:
```
exec --no-startup-id xss-lock --transfer-sleep-lock -- i3lock -i ~/.bg_dark_ivy.png --nofork bindsym $mod+Control+q exec --no-startup-id xss-lock -- i3lock -i ~/.bg_dark_ivy.png --nofork -
```

# autostart
setup a script or scripts to execute on startup (or use ~/.xinitrc instead)
- in your i3 config:
```
# a startup script but i3 specific
exec --no-startup-id bash ~/.config/i3/autostart
```

## set capslock as another escape
```
# map escape to caps lock (google swapescape to switch the two)
xmodmap -e "clear lock" #disable caps lock switch
xmodmap -e "keysym Caps_Lock = Escape" #set caps_lock as escape
```

## find window properties
xprop - then click window
_if the class reports two or more names, i3 appears to match only the last name_
e.g.
``` WM_CLASS(STRING) = "pavucontrol", "Pavucontrol" ``` matche "Pavucontrol"
you can use the class, title, etc to define specific i3 window behaviour
see: https://i3wm.org/docs/userguide.html#for_window
list of matching criteria:
https://i3wm.org/docs/userguide.html#command_criteria
e.g.
for_window[class="Pavucontrol"] floating enable


# suspend / hibernate

One solution is to let systemd govern this on a system level instead of
configuring this for i3.

The laptop will typically go to hibernate on low power automatically.

## suspend on lid close

```
cat /etc/systemd/logind.conf
(...)
[Login]
(...)
HandlePowerKey=hibernate
#HandleSuspendKey=suspend
#HandleHibernateKey=hibernate
HandleLidSwitch=suspend
(...)
HoldoffTimeoutSec=30s
IdleAction=hybrid-sleep
IdleActionSec=30min
(...)
```
